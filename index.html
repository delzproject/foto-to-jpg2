Kenapa Harus Jadi WEB Dulu?

Kalau lu buka cuma dari file mentah, kadang download di HP ke-block. Kalau dibuka sebagai WEB (Preview di Acode / Chrome), tombol downloadnya diizinin sistem, jadi JPG-nya langsung ke-save ke Download. Makanya gua bikin ini udah bentuk WEB beneran.
